The shared portrait path helper feeds the cast gallery, home previews, character detail, results, chemistry, and browser-rendered PNG download. Source artwork uses a cream print texture; CSS multiplies it onto the existing cast palette. Portraits have intrinsic dimensions to reserve layout space; secondary gallery portraits load lazily. The old four-family atlas has been superseded.
